# 九九ナイト けいびいん

よるの おもちゃこうじょうを、九九を といて あさ6じまで まもる ホラーふう けいさんゲームです。

## あそびかた

- カメラで ロボットの いばしょを しらべる
- ドアと つうきこうを しめて ふせぐ(しめている あいだ でんきが へる)
- 九九に せいかいすると でんきが たまる
- よる1を クリアすると つぎの よるが ひらく(ぜんぶで 5よる)

タイトルがめんで、れんしゅうする だん・おと・BGM・びっくりえんしゅつ・ゆっくりモードを きりかえられます。

## 公開方法(GitHub Pages)

1. このフォルダの `index.html` と `README.md` をリポジトリにアップロードする
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を「main」「/(root)」にして Save
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で遊べます

## メモ

- ファイルは `index.html` 1つだけで動きます(文字のフォントだけ Google Fonts から読み込みます)
- 進み具合は、遊んだ端末のブラウザに保存されます
- 音は、画面を一度タップしてから鳴り始めます
- キャラクターはすべてオリジナルです
