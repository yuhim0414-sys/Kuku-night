# 九九ナイト けいびいん

よるの おもちゃこうじょうを、九九を といて あさ6じまで まもる ホラーふう けいさんゲームです。

## あそびかた

- カメラで ロボットの いばしょを しらべる
- ドアと つうきこう(よる3から)を しめて ふせぐ。しめている あいだは でんきが へる
- 九九に せいかいすると でんきが たまる。むずかしい だんほど たくさん たまる(1のだん +3% 〜 9のだん +9%)
- まちがえても デメリットなし。こたえが でて、あとで もういちど でる
- よるを クリアすると つぎの よると、ひみつファイルが ひらく(だい1しょう 9よる＋だい2しょう 5よる)

## アーカイブ

- ファイル: よるを クリアすると よめる ものがたり 10まい(だい1しょうで 5まい、だい2しょうで 4まい、さいごの 1まいは かくし)
- ロボット: であった ロボットの ずかん
- だん: だんごとの せいかい・まちがいの かず と バッジ(5・15・30もん)
- アイテム: その だんで せいかいすると かくりつで てにはいる ぶひん と カセット(きんバッジで カセット かくてい)

## せってい

おと・BGM・おんりょう・えんしゅつの つよさ は だれでも かえられます。
むずかしさ・九九の でかた・こたえかた(3たく/4たく/すうじ)・アイテムの でやすさ・よるの ロック・きろくの かきだし/よみこみ は、「せんせい・おうちの ひと よう」ボタンを 2びょう ながおし すると ひらきます。

ロボットの つよさを じぶんで きめる「カスタムナイト」は、だい2しょうの よる5を クリアすると ひらきます。

## 公開方法(GitHub Pages)

1. このフォルダの `index.html` と `README.md` をリポジトリにアップロードする
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を「main」「/(root)」にして Save
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で遊べます

## メモ

- ファイルは `index.html` 1つだけで動きます(文字のフォントだけ Google Fonts から読み込みます)
- 記録は遊んだ端末のブラウザに保存されます。別の端末へは、設定の「かきだす」「よみこむ」で移せます
- 音は、画面を一度タップしてから鳴り始めます
- キャラクターと物語はすべてオリジナルです
